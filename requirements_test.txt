# pytest-homeassistant pins the whole Home Assistant test stack -- freezegun
# included -- so nothing here may pin those transitively. It is the official
# harness, published from home-assistant/core with Home Assistant's own version
# number. Its predecessor, pytest-homeassistant-custom-component, stopped at
# 2026.10 and cannot start 2026.11 (which aliases `httpx` to `httpx2` at import
# and refuses to run once `httpx` is loaded). Never install both: their
# fixtures overlap.
#
# This pin is the declared floor, not merely a recent version: it carries
# Home Assistant 2026.11, which is what hacs.json declares as the minimum.
# Testing against anything newer would leave the floor itself unexercised, and
# the claim in hacs.json unbacked -- which is the only failure mode a version
# floor has. The matrix in validate.yml tests the floating latest alongside it,
# tolerating its failure.
#
# BETA: 2026.11.0b6 is the newest harness on PyPI; 2026.11.0 itself is not
# published yet. validate.yml installs `homeassistant==2026.11.0` over it, so
# the floor tested is the real release. Move this to 2026.11.0 when it exists.
pytest-homeassistant==2026.11.0b6

# The new harness no longer brings pytest-cov, which the coverage gate needs.
pytest-cov

# 2.15.7, and the two-week gap before this bump is the whole argument for
# watching this pin.
#
# PRONOTE 2026.2.5.6 changed the challenge exchange: `challenge` stopped being
# an AES blob to decrypt, un-alea and re-encrypt, and became a plain string to
# encrypt as it stands. pronotepy 2.15.7 (2026-09-03) is three lines in
# `ClientBase._login` doing exactly that, under a commit named `fix
# compatibility with PRONOTE 2026.2.5.6`.
#
# Against a school already on 26.2.5, 2.15.6 therefore fails *every* login --
# every mode, not only QR, since `_login` is common to all of them -- and it
# fails as `CryptoError("Decryption failed while trying to un pad")`, to which
# upstream appends "probably the qr code has expired" whenever the mode is
# `qr_code`. That message is a guess, not a finding, and it cost most of a day:
# no key derivation can unpad a string that was never ciphertext.
pronotepy==2.15.7
ruff==0.17.4
mypy==2.4.1
